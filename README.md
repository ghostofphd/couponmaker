# Coupon Maker

커미션용 쿠폰 이미지를 간단하게 만들고 저장할 수 있는 프로그램입니다.

## 주요 기능

-   원하는 배경 이미지와 도장 이미지 업로드
-   쿠폰 제목, 신청인, 발행일자 입력
-   첫 번째·두 번째 혜택 문구 설정
-   제목·밑줄·본문·빈칸 색상 변경
-   제목 밑줄 표시 여부 설정
-   빈칸 스타일 선택: 점선 원 / 점선 사각형 / 없음
-   도장 스타일 선택: 원 / 네모 / 원본
-   TTF 폰트 직접 적용
-   쿠폰 위 요소를 마우스로 드래그해 위치 조정
-   선택한 요소를 방향키로 1px씩 세밀하게 이동
-   위치 초기화 및 위치 잠금
-   도장 칸을 클릭해 개별 도장 표시/해제
-   PNG / JPG 이미지 저장
-   쿠폰 설정 초기화

## 사용 방법

1.  `index.html`을 브라우저에서 엽니다.
2.  배경 이미지와 도장 이미지를 업로드합니다.
3.  쿠폰 이름, 혜택 문구, 신청인, 발행일자 등을 입력합니다.
4.  필요한 경우 색상, 폰트, 빈칸 및 도장 스타일을 조정합니다.
5.  쿠폰 미리보기에서 제목·신청인·발행일자·도장 영역을 클릭한 뒤
    드래그하거나 방향키로 위치를 조정합니다.
6.  배치가 끝났다면 `위치 잠금`을 사용할 수 있습니다.
7.  완성된 쿠폰은 PNG 또는 JPG로 저장합니다.
